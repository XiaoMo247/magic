# Magic 传声局：三人快速上手

## 一句话说明

三个人玩一轮“传声筒”：AI 把原句告诉第一位玩家，第一位复述给第二位，第二位复述给第三位，第三位最后猜原句。系统记录每一棒的文字和录音，公开时再看这句话是在哪一步变形的。

这不是狼人杀，也没有隐藏身份、投票或淘汰。游戏的悬念来自信息逐棒损失，以及最后一位能不能从不完整的内容中猜回原句。

## 三个人分别做什么

- 小满：房主，创建房间并负责开始；第一轮第一个传声；
- 阿岛：加入房间，第一轮第二个传声；
- 北北：加入房间，第一轮最后猜测。

房主没有额外分数。每轮结束后，起始玩家会轮换，让三个人都体验传声和猜测：

```text
第 1 轮：小满传声 → 阿岛传声 → 北北猜
第 2 轮：阿岛传声 → 北北传声 → 小满猜
第 3 轮：北北传声 → 小满传声 → 阿岛猜
```

## 开始一局

### 1. 启动

```bash
go run ./backend
```

```bash
cd frontend
npm run dev
```

三个人打开 <http://localhost:5173>。使用 Chrome 或 Edge，并允许麦克风权限。

### 2. 创建和加入

1. 小满输入昵称，点击“创建房间”，得到 4 位房间码，例如 `AB7K`。
2. 阿岛和北北分别输入昵称与 `AB7K`，点击“加入”。
3. 三个人都点击“我准备好了”。
4. 小满点击“开始游戏”。

## 第一轮示例

AI 的原句是：

> 穿蓝色雨衣的人，在车站买了一杯热豆浆。

### 小满：第一棒

小满是第一棒，可以看到原句并听到 AI 播报。小满按住按钮说：

> 穿蓝色雨衣的人，在车站买了一杯豆浆。

小满提交后，阿岛只能看到或播放小满刚刚传来的内容，看不到 AI 原句。

### 阿岛：第二棒

阿岛听小满的录音，再按住按钮复述给北北：

> 穿蓝色雨衣的人，在车站买了一杯热牛奶。

这里“豆浆”变成了“牛奶”。北北只能看到阿岛这一棒的内容，也看不到原句。

### 北北：最终猜测

北北进入“最终猜测”阶段，播放阿岛的录音后说出自己认为的原句：

> 穿蓝色雨衣的人，在车站买了一杯热牛奶。

系统公开结果：

```text
AI 原句：穿蓝色雨衣的人，在车站买了一杯热豆浆。
小满：穿蓝色雨衣的人，在车站买了一杯豆浆。
阿岛：穿蓝色雨衣的人，在车站买了一杯热牛奶。
北北猜测：穿蓝色雨衣的人，在车站买了一杯热牛奶。
结果：人物、地点保留，饮品发生变化
```

然后进入第 2 轮，起始玩家轮换为阿岛。

## 一局有多少次操作

三人模式每轮有两次传声和一次最终猜测，共 5 轮：

```text
5 轮 ×（2 次传声 + 1 次猜测）= 15 次语音操作
```

第 5 轮完成猜测后，本局进入结束状态。

## 页面上会看到什么

- 当前回合：只有轮到自己的玩家可以提交；
- 当前传递内容：当前玩家能看到的上一棒文本；
- 上一棒录音：可以点击播放，帮助下一位理解内容；
- 最终猜测：最后一位对原句的猜测；
- 玩家分数：每次传声或猜测后增加匹配分；
- 聊天区：用于提醒“准备好了”或交流现场反应。

## 语音操作

- 鼠标按住“按住开始说”，说完松开；
- 也可以按住空格键说话，松开空格提交；
- 浏览器支持时会同时进行中文语音识别和录音；
- 不支持语音识别时，仍可用演示文本完成流程；
- “重播内容”会用浏览器语音合成朗读当前可见内容；
- 后续接入灵矽后，AI 播报、ASR 和语义判定会由灵矽提供。

## 当前版本的边界

当前版本已经实现真正的接龙状态和信息隔离，但原句仍来自固定题库，计分使用本地字符匹配。灵矽真实 ASR、TTS、LLM 判定和自然语言点评尚未接入，详细情况见 [PROJECT-STATUS.md](PROJECT-STATUS.md)。

第一次介绍游戏时可以这样说：

> “AI 先告诉第一个人一句话，后面的人只能听上一棒，最后一个人猜原句。我们一起看这句话经过三个人之后变成了什么。”
