# 三人快速上手：这游戏到底怎么玩

## 一句话说明

三个人轮流听同一句密令，再用自己的声音复述它。系统把你的复述和原句做匹配，给你一个分数；三个人都说完后换下一句，连续完成 5 轮。

它不是狼人杀，也没有隐藏身份、投票和淘汰。核心乐趣是：你能不能听清并准确复述，队友能不能把接力顺利传下去。

## 三个人分别做什么

假设三位玩家是：

- 小满：房主，负责创建房间和点击开始；
- 阿岛：加入房间，等待轮到自己；
- 北北：加入房间，等待轮到自己。

房主没有额外分数，也不是裁判。三个人的操作完全一样，只是小满多一个“开始游戏”按钮。

## 一局游戏怎么开始

### 1. 启动程序

项目根目录打开两个终端：

```bash
go run ./backend
```

```bash
cd frontend
npm run dev
```

三个人都打开 <http://localhost:5173>。

### 2. 创建和加入

1. 小满输入昵称，点击“创建房间”，得到一个 4 位房间码，例如 `AB7K`。
2. 阿岛输入自己的昵称和 `AB7K`，点击“加入”。
3. 北北也输入自己的昵称和 `AB7K`，点击“加入”。
4. 三个人都出现在右侧“回声小队”列表中。

### 3. 准备并开始

1. 小满、阿岛、北北分别点击“我准备好了”。
2. 三个人都显示“已准备”后，小满点击“开始游戏”。
3. 页面进入第 1/5 轮，第一位玩家是小满。

## 一轮到底发生什么

第一轮密令假设是：

> 雨后的电车穿过橘色隧道

### 小满的回合

1. 小满看到“你的回合”。
2. 小满点击“重播密令”，先听一遍；也可以直接看页面上的密令文字。
3. 小满按住“按住开始说”，说出自己记住的句子：

   > 雨后的电车穿过橘色隧道

4. 小满松开按钮，系统提交语音识别文本。
5. 假设识别结果是“雨后的电车穿过橘色隧道”，匹配度可能是 99 分。
6. 小满个人分数增加 99，当前玩家切换成阿岛。

### 阿岛的回合

阿岛看到“你的回合”后，做同样的事情：

1. 重播或阅读密令；
2. 按住按钮说出整句；
3. 松开按钮提交；
4. 查看自己的匹配度。

假设阿岛说成“雨后的电车穿过橙色隧道”，少了“橘”字，可能得到 90 分左右。

### 北北的回合

北北完成同样的操作。北北提交后，第一轮结束，进入第 2/5 轮，密令变成下一句：

> 月亮把影子藏进玻璃杯

然后仍然从小满开始，依次是：

```text
小满 → 阿岛 → 北北
```

## 三人一局有多少次操作

总共 5 轮，每轮 3 个人各说 1 次：

```text
第 1 轮：小满、阿岛、北北
第 2 轮：小满、阿岛、北北
第 3 轮：小满、阿岛、北北
第 4 轮：小满、阿岛、北北
第 5 轮：小满、阿岛、北北
```

所以三人完整玩完一局，需要完成 15 次“按住说话 → 松开提交”。第 5 轮北北提交后，本局结束。

## 分数怎么看

每次说完都会得到一个匹配度，范围是 45–99 分：

- 说得越接近密令，分数越高；
- 个人分数显示在右侧玩家列表；
- 团队进度是三个人分数的汇总展示；
- 当前版本没有胜负淘汰，主要目标是一起完成 5 轮并争取高分。

例如三人第一轮得分如下：

| 玩家 | 第 1 轮得分 | 个人累计分 |
| --- | ---: | ---: |
| 小满 | 99 | 99 |
| 阿岛 | 90 | 90 |
| 北北 | 78 | 78 |

第二轮完成后，每个人的新分数会继续累加。

## 语音按钮怎么用

- 鼠标：按住“按住开始说”，说完松开；
- 键盘：按住空格说话，松开空格提交；
- Chrome / Edge：会尝试使用中文语音识别，需要允许麦克风；
- 不支持语音识别时：仍然可以点击完成演示，系统会使用演示回声计算分数；
- “重播密令”：使用浏览器语音合成朗读当前密令。

## 三人试玩时最容易误解的地方

### 这不是“下一个人只能听上一个人说的内容”

当前原型中，密令文字对所有玩家可见，且每一轮所有人复述同一条密令。它先用于演示语音识别、轮流和计分闭环。

### 当前版本不是接力记忆链

现在每轮结束后会换一条新密令，不会把上一位玩家的句子自动传给下一位。后续可以升级为“下一位只能听上一位的录音”，让记忆偏差成为游戏核心。

### 倒计时目前主要是提示

页面显示 24 秒倒计时，但当前后端不会在时间到后自动判定失败。正式比赛版可以增加超时自动跳过和扣分规则。

## 三人试玩的推荐说法

第一次向别人介绍时，可以直接说：

> “我们三个人轮流说同一句话。先听密令，轮到你时按住按钮复述，系统按说得像不像给分。每人每轮说一次，一共 5 轮，最后看谁分高、团队能不能拿满进度。”
