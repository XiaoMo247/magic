# 项目阶段性情况说明

## 一、项目名称

回声密令（灵矽应用语音游戏创意赛作品）

## 二、当前已完成内容

本项目已完成 Vue + Go 的基础架构和可运行原型，主要包括：

- Vue 3 + Vite 前端；
- Go HTTP 房间服务；
- 创建房间、加入房间、玩家准备和房主开始；
- 3–8 人房间及轮流回合；
- 语音接龙状态机：传递阶段、最终猜测阶段和结束阶段；
- 玩家私有视图：原始密令不会展示给非当前玩家；
- 浏览器中文语音识别回退；
- 浏览器 `MediaRecorder` 录音并传递上一棒录音；
- 匹配度计分、玩家积分、团队进度和聊天；
- Go API 单元测试、前端生产构建和 GitHub Actions CI；
- 三人、五人游玩说明及比赛演示文档。

## 三、当前未完成内容

受开发周期和单人开发资源限制，以下内容未能在截止时间前完成：

1. 尚未接入灵矽真实 ASR、TTS 和大模型接口；当前使用浏览器 Web Speech API、浏览器语音合成和本地演示逻辑。
2. 尚未完成灵矽 WebSocket/SSE 生产级适配，包括 API Key 管理、鉴权、重试和服务降级。
3. 录音暂时以 `data:` 数据保存在 Go 进程内存中，未接入对象存储和持久化数据库，不适合生产规模使用。
4. 房间状态当前保存在单个 Go 进程内存中，服务重启后房间会丢失，尚未接入 Redis、数据库或分布式状态同步。
5. 多人同步当前采用 1 秒轮询，尚未升级为 WebSocket 实时推送。
6. 尚未完成断线重连、超时自动判定、房间过期、重复提交幂等和完整的生产安全策略。
7. 最终猜测目前使用本地字符匹配，尚未使用灵矽大模型进行语义相似度判断和自然语言点评。

## 四、未完成原因

本项目由一名开发者独立完成。开发周期较短，且需要同时完成产品设计、前后端开发、接口调试、测试、文档和比赛交付。为保证截止时间前有可演示成果，开发优先实现了核心游戏流程和可运行闭环，将灵矽真实服务接入、生产化存储和实时通信列为后续工作。

因此，当前提交版本属于“可运行的比赛原型”，不是完整生产版本。未完成部分不影响评审人员体验创建房间、多人准备、轮流接龙、最终猜测和结果展示等核心流程，但灵矽平台的真实 AI 能力尚未在本版本中实际调用。

## 五、后续开发计划

后续将按以下顺序完成：

1. 在 Go 后端增加 `VoiceProvider` 接口，并保留 Mock 实现；
2. 接入灵矽 ASR/TTS，API Key 只保存在后端；
3. 使用灵矽智能体和大语言模型生成密令、判定语义相似度并生成点评；
4. 将录音迁移到对象存储，房间和回合迁移到 Redis/数据库；
5. 使用 WebSocket 替换轮询，增加断线重连和超时处理；
6. 增加完整比赛模式、回放、数据统计和部署配置。

## 六、交付结论

截至提交时，本项目已具备完整的语音接龙玩法原型和可复现的本地运行方式，核心流程可以演示。灵矽真实 SDK、生产级基础设施和部分高级 AI 能力因单人开发及时间限制未能及时完成，特此说明。
