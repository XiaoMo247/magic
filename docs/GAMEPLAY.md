# Magic 传声局：五人完整游戏流程

本文以 5 名玩家为例，说明 `Magic 传声局（Magic Relay）` 的真实玩法、状态变化和比赛演示方式。

## 1. 游戏目标

灵矽 AI 先生成一句密令并告诉第一位玩家。玩家依次复述，后面的玩家只能听上一棒的内容，最后一位玩家猜测最初的原句。每轮结束后展示传声链和得分，重点观察信息如何在语音传递中发生变化。

这是一款合作型语音接龙游戏，不设置狼人、隐藏身份、投票或淘汰。完成 5 轮后结束本局，个人分数和团队进度用于展示传递质量。

## 2. 五人角色和轮换

| 玩家 | 身份 | 第 1 轮职责 |
| --- | --- | --- |
| 小满 | 房主 | 第一棒传声 |
| 阿岛 | 普通玩家 | 第二棒传声 |
| 北北 | 普通玩家 | 第三棒传声 |
| 你 | 普通玩家 | 第四棒传声 |
| 禾木 | 普通玩家 | 最后一棒猜测 |

房主只负责创建和开始，不拥有额外信息。每轮结束后起始玩家向后轮换一位：

```text
第 1 轮：小满传 → 阿岛传 → 北北传 → 你传 → 禾木猜
第 2 轮：阿岛传 → 北北传 → 你传 → 禾木传 → 小满猜
第 3 轮：北北传 → 你传 → 禾木传 → 小满传 → 阿岛猜
第 4 轮：你传 → 禾木传 → 小满传 → 阿岛传 → 北北猜
第 5 轮：禾木传 → 小满传 → 阿岛传 → 北北传 → 你猜
```

一局共 5 轮，每轮 4 次传声和 1 次猜测，总计 25 次语音操作。


访问 <http://localhost:5173>。比赛现场建议使用 Chrome 或 Edge，并允许麦克风权限。

1. 小满输入昵称，点击“创建房间”。
2. 阿岛、北北、你、禾木输入房间码并加入。

## 4. 第一轮示例

AI 原句：

> 戴红帽子的女孩在八点十五分经过三号地铁口。

### 小满传给阿岛

只有小满能看到原句。小满听 AI 播报后按住按钮复述：

> 戴红帽子的女孩在八点十五分经过三号地铁口。

小满提交录音和识别文本。阿岛此时看不到 AI 原句，只能播放小满的录音或查看小满传来的文本。

### 阿岛传给北北

阿岛听到上一棒后复述：

> 戴红帽子的女孩在八点半经过三号地铁口。

时间从“八点十五分”变成“八点半”，这是一次信息失真。

### 北北传给你

北北只能听阿岛的内容，再复述给你：

> 戴红帽子的女孩八点半去了三号地铁口。

动作“经过”被说成了“去了”，但人物、时间和地点仍然保留。

### 你传给禾木

你继续复述：

> 红帽子女孩八点半去了三号地铁口。

“戴”这个细节丢失。

### 禾木最终猜测

禾木进入猜测阶段，只能看到你的最后一棒内容，然后猜：

> 戴红帽子的女孩八点半去了三号地铁口。

系统展示完整链路：

```text
AI：戴红帽子的女孩在八点十五分经过三号地铁口。
小满：戴红帽子的女孩在八点十五分经过三号地铁口。
阿岛：戴红帽子的女孩在八点半经过三号地铁口。
北北：戴红帽子的女孩八点半去了三号地铁口。
你：红帽子女孩八点半去了三号地铁口。
禾木猜测：戴红帽子的女孩八点半去了三号地铁口。
```

结果可以描述为：人物和地点保留，时间和动作发生变化，最终猜测基本正确。

## 5. 五轮密令示例

| 轮次 | 示例原句 | 最后一位猜测者 |
| --- | --- | --- |
| 第 1 轮 | 戴红帽子的女孩在八点十五分经过三号地铁口。 | 禾木 |
| 第 2 轮 | 周五晚上，小林在便利店买了两杯柠檬茶。 | 小满 |
| 第 3 轮 | 三只蓝色纸船顺着河流漂到桥下。 | 阿岛 |
| 第 4 轮 | 月亮把一把银色钥匙藏进了玻璃杯。 | 北北 |
| 第 5 轮 | 森林尽头亮起一盏紫色信号灯。 | 你 |

当前代码使用固定题库；接入灵矽后可以改为按主题和难度动态出题。

## 6. 计分规则

当前原型使用字符级匹配作为本地回退：

1. 去除标点和空格；
2. 统计识别文本和上一棒目标文本的重复字符；
3. 得到 45–99 分的匹配度；
4. 传声分数累计到当前传声玩家；
5. 最终猜测分数累计到猜测玩家；
6. 团队进度根据全队累计分数展示。

正式接入灵矽后，计分应改为语义比较，重点判断人物、地点、时间、数量、动作和关键物品是否保留。

## 7. 页面状态和信息权限

- `lobby`：等待加入和准备；
- `playing + relay`：当前玩家传声，后续玩家看不到原句；
- `playing + guess`：最后一位根据上一棒内容猜测；
- `finished`：展示最终结果和排行榜。

后端查询房间时携带 `player_id`，因此不同玩家收到的内容不同。非当前玩家不会拿到当前传递文本，避免通过刷新接口偷看原句。

## 8. 比赛现场演示脚本

1. 启动 Go 和 Vue，打开 5 个浏览器窗口。
2. 小满创建房间，把房间码发给其他四人。
3. 五人加入并全部准备。
4. 房主开始游戏，说明只有第一棒能看到 AI 原句。
5. 依次展示 4 次传声和最后一次猜测。
6. 播放每一棒录音，展示原句和最终猜测的变化。
7. 再演示第 2 轮起始玩家轮换。
8. 说明当前使用浏览器语音和固定题库，灵矽真实 ASR/TTS/LLM 接入属于后续工作。
