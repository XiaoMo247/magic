# 回声密令

“灵矽应用：语音类游戏”比赛原型。一个 3–8 人的语音记忆接力游戏：玩家依次听到逐步变长的密令，按住麦克风复述，系统根据语音识别匹配度给分。

## 初始化与运行

当前仓库是零依赖静态前端，不需要安装 Node。直接在浏览器打开 `index.html` 即可试玩；也可以在仓库目录运行：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 后续接入灵矽语音能力

原型中的 `app.js` 已将录音交互、识别结果和匹配度展示拆开。当前优先使用浏览器原生 `SpeechRecognition`（Chrome/Edge），会把识别文本与密令做字符匹配并计算分数；不支持该 API 的浏览器会自动使用演示回声，不影响比赛现场展示。

生产环境接入灵矽语音 SDK 时，可替换 `startRecording` / `finishRecording` 中的识别适配层：申请麦克风权限、提交音频流、读取 ASR 文本，再复用现有匹配度与 UI 状态即可。真实麦克风识别通常需要 HTTPS 或 `localhost`。
